# Rain in Chiang Mai · ฝนเชียงใหม่

https://nanobotco.github.io/rain-chiang-mai/

One page. The top answers "is it raining in Chiang Mai right now?" in the browser: it samples the latest RainViewer radar frame within 3.5 km of the chosen place (and 25 km for "nearby"), and reads the current 15-minute block and 12-hour chances from Open-Meteo. Below: monthly normals, rain clock, royal rainmaking, floods, legends, sources.

Edit `docs/index.html` directly. `tools/card.html` renders `docs/card.jpg` in headless Chrome.

Rain clock numbers come from the weather-north project (Chiang Mai METAR, Sep 2024 – Sep 2026).
